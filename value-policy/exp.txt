The Next Chevron Experiment
Value, Policy, and Memory Under Reversal

So far, Chevron Nets have lived mostly in small supervised tasks, memory sketches, and architectural comparisons. That has been useful: it let me separate the three regimes — Free, Structured, and Complex — and show that they are not just different names for the same thing.

But if Chevron Nets are going to matter, I doubt it will be because they do slightly better on another static classification task.

My stronger suspicion is this:

Chevron Nets matter, if they matter, because they offer a different way to couple memory, control, and revision over time.

That means reinforcement learning is probably the right next arena.

The cleanest first test, I think, is a Structured Value / Policy Chevron on a tiny RL task with noisy evidence, hidden context, and occasional reversals. The goal is not to beat every standard architecture. The goal is to test one narrow but important claim:

Does local coupling between proposal and critique help an agent remember, revise, and sometimes hold back?

Below is a concrete experiment sketch.

Why this task

This task is still small enough that an LSTM should solve it. That is desirable. The question is not whether Chevron Nets are the only workable recurrent model. The question is whether local proposal/control coupling gives cleaner reversal recovery and better calibrated caution under matched training conditions.

4. Baselines

For the first implementation, compare five models and keep the rest fixed.

Baseline 1: MLP actor–critic

Observation encoder + shared trunk + separate policy/value heads.

No recurrence.

Baseline 2: GRU actor–critic

Same observation input, recurrent hidden state, separate heads.

This is the strongest lightweight recurrent baseline.

Baseline 3: LSTM actor–critic

Same observation input, recurrent hidden state, separate heads.

This is the strongest obvious baseline for a tiny task requiring memory.

Baseline 4: Free Chevron actor–critic

Two-channel state and full 2×2 mixing, but no semantic role constraints.

This tests whether “two channels plus more structure” helps by itself.

Main model: Structured Value / Policy Chevron

Two channels assigned explicit roles:

policy/proposal

value/control

with local coupling.

11. What would count as a real result?

Not necessarily “highest reward wins.”

A real result would look like this:

the Structured Chevron matches or beats the GRU/LSTM baselines on mean reward,

recovers faster after reversals,

makes more use of 
𝑊
W immediately after reversal without collapsing into always-wait behavior,

makes fewer premature commits under ambiguity,

and shows a clear causal asymmetry between

𝑉

That would be enough to justify the next step.

The stronger claim would not be:
“Chevron Nets solve RL.”

It would be:

A locally coupled Value / Policy architecture can turn actor–critic from an output-level decomposition into a recurrent state-level one, and that appears useful when an agent must both remember and revise.

That would already be interesting.

12. Why this experiment comes before Self / World

The Self / World regime is probably the deeper idea. But it is harder to operationalize cleanly.

Value / Policy has two advantages:

RL already knows how to evaluate it.

The decomposition is uncontroversial.

So this experiment is the right first step.

If it works, then the next move is obvious:
replace Value / Policy with Self / World, and move from tiny reversal bandits to a small POMDP or model-based task where the distinction between internal stance and world evidence becomes more meaningful.

13. Pseudocode sketch

Here is a compact implementation sketch.

# State
P = zeros(batch, hidden)
V = zeros(batch, hidden)

for t in range(T):
    o_t = obs[:, t]                      # observation at time t
    h_t = tanh(Wo(o_t) + bo)

    uP = Wp(h_t) + bp
    uV = Wv(h_t) + bv

    # Chevron local mixing
    P_mix = mPP * P + mPV * V + uP
    V_mix = mVP * P + mVV * V + uV

    P_tilde = tanh(P_mix)
    V_tilde = tanh(V_mix)

    # Tension-style collapse
    ell = P_tilde - V_tilde
    p = sigmoid(ell)
    gain = sqrt(eps + p * (1 - p))

    # Optional TD error from previous step
    # delta = reward_t + gamma * value_next - value_now

    # Fast state update
    P = (1 - lambda_P) * P + eta_P * gain * P_tilde
    V = (1 - lambda_V) * V + eta_V * gain * V_tilde

    # Readouts
    policy_logits = Wpi(P)              # or concat(P, V), or gated version
    value_pred = Wval(V)                # or concat(P, V)

    # sample action / store rollout

Training can then use PPO/A2C in the usual way.

14. Why I find this compelling

What I like about this experiment is that it is small enough to be honest.

It does not require frontier models, giant datasets, or vague claims. It asks one concrete question in a setting where the architecture’s biases should actually matter. A standard actor–critic can already act. An LSTM can already remember. The Chevron hypothesis is narrower:

perhaps a paired-channel recurrent cell can do better when action requires not just memory, but memory under critique.

That feels like the right next test.

Closing

So that is the next experiment I want to try: a Structured Value / Policy Chevron on a tiny reversal-style RL problem, with enough recurrence to make memory matter and enough ambiguity to make control matter too.

If Chevron Nets have a future, I suspect it will begin there.
